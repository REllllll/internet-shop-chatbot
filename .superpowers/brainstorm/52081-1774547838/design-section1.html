Monorepo Layout

internet-shop-chatbot/
├── frontend/             # React chat UI
│   ├── src/components/   # ChatWindow, MessageBubble, ProductCard
│   ├── src/hooks/       # useChat (SSE connection)
│   └── Dockerfile

├── backend/              # FastAPI + MCP server
│   ├── app/
│   │   ├── main.py      # FastAPI entry point
│   │   ├── chat.py      # /chat SSE endpoint, conversation loop
│   │   ├── mcp_tools.py # product_search, filter, compare tools
│   │   └── db.py       # SQLite queries
│   ├── requirements.txt
│   └── Dockerfile

├── workflows/           # n8n workflow JSON exports
│   ├── recommendation-pipeline.json
│   └── product-indexing.json

├── data/
│   ├── raw/amazon.csv   # Kaggle dataset (committed)
│   ├── seed.py         # CSV → SQLite loader
│   └── products.db     # SQLite DB (gitignored)

├── docker/
│   └── docker-compose.yml

├── docs/
│   ├── superpowers/specs/  # agent design docs
│   └── guidlines/        # existing interim report

├── CLAUDE.md
├── .env.example
└── .gitignore

Four Services in docker-compose

frontend :3000
React + Vite
Chat UI, SSE connection to backend
backend :8000
FastAPI
Chat API, MCP tools, Claude calls
n8n :5678
Self-hosted n8n
Recommendation pipeline workflows
SQLite (file)
